2Get the project on your laptop

  1. Install Git if you don't have it: git-scm.com
  2. Open a terminal in the folder where you want the project and run:
    git clone https://github.com/Amm2049/duesoon.git
  3. In VS Code: File → Open Folder → choose the new duesoon folder.
  4. When I tell you I updated something, run this inside the folder:
    git pull

Please don't edit the files. You can't push to the repo anyway, but local edits can block git pull. If it complains, run git restore . and then git pull again.

3Learn your part with the guide

  1. Step-by-step flows first: they follow one action (like tapping Log in) through the files in order, from the screen to the database.
  2. Every file + code: what each of your files does and its important lines. Click a line N link to jump to it.
  3. Practice questions and Project-wide questions: what the professor may ask. Try answering before opening.

4Practise finding code in VS Code

Ctrl + POpen a file by typing its name, e.g. login_screen
Ctrl + GJump to a line number from the guide
Ctrl + Shift + FSearch the whole project, e.g. _submit
Ctrl + clickOn a name in the code: go to where it is defined
